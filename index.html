Continuity insurance for visa dependent critical talent, and the companies that cannot afford to lose them.

Builder

Retail Crew Dashboard

Working MVP

AI crew orchestrator that automates task assignment for retail store teams.

Store associates create customer facing requests: a size lookup, fitting room support, a price check, a restock, an escalation. The system detects the request type, reads the store situation level, and broadcasts the task to LLM backed crew agents, one per crew member, which reply accept, decline, or counter with an ETA. A deterministic scoring layer selects the winner, and an orchestrator agent writes the action plan.

High severity requests route to a manager approval queue, so no plan commits without a human where it matters. A coach agent turns per crew performance analytics into written coaching reports. Built with Next.js, React, TypeScript, Supabase Postgres, and Gemini, with atomic rate limits, an append only audit log, transactional migrations, and unit tests covering the deterministic core.

  • Multi agent broadcast
  • Deterministic winner selection
  • Manager approval queue
  • Coach agent reports
  • Gemini 2.0 Flash
